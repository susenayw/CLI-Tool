# ⚡ DevPulse CLI

> A high-utility, modular Command-Line Interface (CLI) tool built in Python for real-time weather querying and text/file processing.

---

## 🚀 Features

* 🌤️ **Live Weather Updates:** Query current weather (temperature, humidity, wind speed) for any city globally using Open-Meteo API.
* 📊 **File Statistics:** Quickly calculate lines, words, and character counts for any document.
* 🔄 **Data Conversion:** Easily convert raw CSV files into formatted JSON datasets.
* 🎨 **Rich Terminal UI:** Clean, colorized output and custom tables rendered directly in the terminal.
